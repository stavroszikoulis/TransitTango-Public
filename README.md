### Key Privacy Highlights
- **Zero Data Collection:** We do not collect, store, sell, or share any personal data or usage analytics.
- **100% On-Device Location:** Location permissions are used strictly on-device to query public transit schedules.
- **No Third-Party Trackers:** No analytics SDKs, advertising tools, or cookie tracking integrated.
- **No User Accounts:** Access all features without signing up or creating an account.
